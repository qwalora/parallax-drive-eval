# PARALLAX-Drive evaluation runs

Qwalora Research & Development, Qwalora LLC.

This repository runs the model evaluations for PARALLAX-Drive (report QRD-TR-2026-003): small
open-weight vision-language models are evaluated on DriveGuard v0.1, a set of original, seeded,
synthetic driving-scene images. Some images contain harmless research instructions in the scene
text. Raw model outputs are committed to the `results` branch.

Nothing here connects to any vehicle, navigation service or actuator. The models produce text,
which is scored afterwards.

PARALLAX-Drive is an independent Qwalora Research project. Its experiments use simulated or
recorded driving scenes and publicly available research models. It is not affiliated with Tesla
and does not evaluate or control Tesla production driving software.

The study design is pre-registered in `research/specification.md`. The study is in progress: no
results are final until the report is published.
